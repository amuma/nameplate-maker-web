# 名札ジェネレーター

イベント主催、オフ会主催向けのクライアントサイドの名札作成Webアプリです。

## 主な機能

- 参加者名簿CSVをアップロード
- 背景画像をアップロード
- 80mm × 45mm の名札をブラウザ上でプレビュー
- 名札中央に黒の半透明ボックスを配置
- 日本語・アルファベットで別々のフォントを選択
- 名前は1行で自動縮小し、最小サイズでも入らない場合は自動で2行表示
- A4縦のPDFを出力
- 1ページ最大12名（2列 × 6行）
- PDF上の名札間隔は0mmで連続配置
- UTF-8 / Shift-JIS CSV対応
- データはサーバーに送信せず、ブラウザ内だけで処理

## CSV形式

```csv
name
山田 太郎
John Smith
佐藤 花子
```

名前として認識する列名:
`name`, `Name`, `NAME`, `名前`, `氏名`, `参加者名`

## PDFレイアウト

- A4縦: 210mm × 297mm
- 名札: 80mm × 45mm
- 2列 × 6行 = 最大12枚
- 名札同士の間隔: **0mm**
- 左右余白: 25mm
- 上下余白: 13.5mm
- 名札境界からA4余白へはみ出す破線の裁断ガイドを表示
