# 名札PDFジェネレーター

GitHub Pagesで公開できる、完全クライアントサイドの名札作成Webアプリです。

## 主な機能

- 参加者名簿CSVをアップロード
- 背景画像をアップロード
- 名札の横幅・縦幅をmm単位でフォーム指定（初期値80mm × 45mm）
- 指定した縦横比で名札をブラウザ上にプレビュー
- 名札中央に黒の半透明ボックスを配置
- 日本語・アルファベットで別々のフォントを選択
- 名前は1行で自動縮小し、最小サイズでも入らない場合は自動で2行表示
- A4縦のPDFを出力
- 指定サイズに応じてA4内の最大列数・行数を自動計算
- PDF上の名札間隔は0mmで連続配置
- UTF-8 / Shift-JIS CSV対応
- データはサーバーに送信せず、ブラウザ内だけで処理

## CSV形式

```csv
name
山田 太郎
John Smith
佐藤 花子
```

認識する列名:
`name`, `Name`, `NAME`, `名前`, `氏名`, `参加者名`

## GitHub Pagesで公開

1. GitHubでリポジトリを作成
2. このフォルダのファイルをリポジトリ直下に配置
3. `Settings` → `Pages`
4. Source: `Deploy from a branch`
5. Branch: `main` / Folder: `/(root)`
6. Save

## PDFレイアウト

- A4縦: 210mm × 297mm
- 名札: フォームで横幅・縦幅を指定
- 80mm × 45mmの場合: 2列 × 6行 = 最大12枚
- 名札同士の間隔: **0mm**
- 配置領域はA4中央揃え
- 破線ガイド用に外周8mm以上を確保
- 名札境界からA4余白へはみ出す破線の裁断ガイドを表示
